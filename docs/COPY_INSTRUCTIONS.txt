AIRLINE EMPIRE - NORTH AMERICA 88 CITY ASSETS

COPY TARGET

Copy the included "game" folder into the root of the AirlineEmpire repository.
Allow Windows to merge folders when prompted.

The 88 runtime images will land here:

game/assets/city-skylines/

The files are named by lowercase IATA code, for example:

game/assets/city-skylines/abq.webp
game/assets/city-skylines/atl.webp
game/assets/city-skylines/jfk.webp
game/assets/city-skylines/yvr.webp

RUNTIME FORMAT

- 88 WebP files
- 360 x 176 pixels each
- Existing artwork preserved
- City names and IATA labels remain game-rendered HTML/CSS
- No contact-sheet image needs to be copied into the game

REFERENCE FILES

- north-america-88-game-assets.csv lists every included city, IATA code, and source file.
- north-america-88-preview.png is a visual reference only.
